# Prashish Paudel — Personal Portfolio

**Live:** [prashishpaudel.github.io](https://prashishpaudel.github.io)

Personal portfolio site built with Next.js and styled-components.

## Stack

- Next.js 10 / React 17
- styled-components
- Deployed via GitHub Pages (`gh-pages`)

## Setup

```bash
npm install
npm run dev       # local dev server
npm run build     # build + export static
npm run deploy    # push to gh-pages branch
```
